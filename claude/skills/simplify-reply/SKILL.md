# Simplify reply

Rewrite your previous reply for the reader:

1. Start the response with a separator line of 75 `━` (U+2501) characters.
2. On the next line: `**Concise version:**`
3. Then rewrite the previous reply. Make this reply concise and easy to understand. Preserve the key facts.
4. Then stop.
